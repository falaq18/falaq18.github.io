# falaq18.github.io

Falaq Chopra's personal site. Plain HTML, CSS and JS, no build step, served by GitHub Pages from `main`.

- `index.html` – the page
- `css/site.css` – design tokens (colour, type, space, shape, motion) at the top, then sections in page order
- `js/site.js` – interactions (nav progress + active section, mobile menu, setlist rail, mixer, brain tabs, question sampler, copy email, encore). The page works without it.
- `img/` – WebP with JPEG fallback

Preview locally: `python3 -m http.server 8000` in this folder, then open http://localhost:8000.
